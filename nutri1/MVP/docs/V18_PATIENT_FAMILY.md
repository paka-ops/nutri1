# NUTRI.N°1 V18 — Patient & Family Care Edition

Built on V17.

## Nutritionist Network
Nutritionists can select an authorized patient and open a patient dashboard with:
- anthropometric indicators
- BMI
- glucose
- blood pressure
- trend visualization
- nutrition status
- prevention signal
- care-plan access

The UI is a demonstration of consent-based access; production deployment should enforce backend authorization, patient consent, audit logs and role-based permissions.

## Family subscriptions
A parent/legal guardian can select a minor child in a family subscription and access:
- height
- weight
- BMI-for-age
- growth status
- nutrition status
- alerts
- child nutrition plan

Production deployment should enforce verified parent/guardian relationships, consent, age rules, access logs and child-data protection.
