# NUTRI.N°1 V52 — Deep Investor Simulation

V52 adds a front-end investor demonstration layer across Ministry of Health, Ministry of Agriculture, UNICEF, WHO, WFP, FAO and Projects/Surveys/Nutrition Surveillance.

It provides interactive workflow simulation for selectors, KPIs, cards, alerts, indicator rows, survey steps, GIS areas and data-product rows. The simulated pipeline demonstrates source synchronization, provenance/quality checks, AI/analytics, GIS/early warning refresh and decision output.

All displayed values are demonstration values and must be replaced by validated authorized datasets in production.
