# NUTRI.N°1 V45 — Citizen Dashboard 360° Only

This version is based on V44 and intentionally changes ONLY Citizen Dashboard 360°.

Added:
- Automatic BMI calculation from weight and height.
- Automatic blood glucose display.
- Automatic blood pressure display from systolic/diastolic values.
- Automatic nutrition score.
- Reference ranges displayed directly below each metric.
- Anthropometry Trends chart.
- Metabolic & Clinical Trends chart.
- Nutrition-linked Clinical Parameters chart.
- Reference Comparison chart.
- Live recalculation when the user changes input values.

No changes are intentionally made to Payments, languages/countries, WHO, UNICEF, scanner, prevention, nutritionist, marketplace, African Food Cloud, Ministry dashboards or Research & Evidence.
