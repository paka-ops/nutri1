# V17 — Full V16 Rebuild + Requested Enhancements

This edition intentionally keeps the V16 information architecture and dynamic visual language, then adds the requested enhancements.

## Investor / Government / Scientific demonstration
The home dashboard clearly exposes the three audiences and the common intelligence infrastructure.

## Multilingual behavior
Changing the language selector updates the visible core navigation and hero labels in the supported UI translations:
- English
- Français
- Português

The country selector also exposes official/local language options for the selected country. Full translation of every screen and all local-language strings requires validated human translations.

- anthropometric trends
