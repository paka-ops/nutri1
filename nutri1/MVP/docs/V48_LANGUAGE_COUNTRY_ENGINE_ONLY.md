# NUTRI.N°1 V48 — Language & Country Intelligence Engine Only

Base preserved: V47.

Scope restriction:
Only the Country → Language selection layer is enhanced. No other application module is intentionally changed.

Country packages:
- Togo: official French + Ewe, Kabyè, Mina, Tem, Ifè, Nawdm, Tchokossi + English/Spanish platform availability
- Ghana: official English + Ewe, Twi, Ga, Dagbani, Fante, Hausa + French/Spanish platform availability
- Côte d'Ivoire: official French + Dioula, Baoulé, Bété, Sénoufo, Attié, Abidji + English/Spanish platform availability
- Senegal: official French + Wolof, Pulaar, Serer, Jola, Mandinka, Soninke + English/Spanish platform availability
- Nigeria: official English + Hausa, Yorùbá, Igbo, Fulfulde, Kanuri, Ibibio + French/Spanish platform availability
- Benin, Burkina Faso, Cabo Verde, The Gambia, Guinea, Guinea-Bissau, Liberia, Mali, Mauritania, Niger, Sierra Leone
- AES extensions: Burkina Faso, Mali, Niger; additional Sahel deployment entries are included for Chad, Cameroon and Central African Republic.

Important distinction:
Official languages are labelled separately from local/important languages. French, English and Spanish are not incorrectly labelled as official in countries where they are not official.

The engine dynamically rebuilds the language list after country selection.
