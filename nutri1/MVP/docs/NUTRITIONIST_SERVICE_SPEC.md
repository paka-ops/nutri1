# Nutritionist Service Specification

## Discovery
Filter by:
- country
- language
- specialty
- consultation mode
- availability

## Communication
- secure chat
- attachments
- consultation notes
- appointment-linked conversations

## Appointment
REQUESTED → CONFIRMED → PAID (if required) → IN_PROGRESS → COMPLETED → FOLLOW_UP

## Human-in-the-loop
Nutritionists can review:
- uncertain AI food scans
- complex meal estimates
- personalized recommendations
- referral needs

Clinical diagnosis remains outside the nutrition recommendation engine unless the appropriate licensed clinical workflow is implemented.
