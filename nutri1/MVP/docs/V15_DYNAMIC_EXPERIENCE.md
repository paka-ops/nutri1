# V15 Dynamic Experience

The product should feel like a living personal health/nutrition cockpit, not a static form.

## Individual
- Dashboard 360°
- latest values
- trends and charts
- goals and progress bars
- notifications
- AI insights
- country/language context
- one-tap scanning
- nutrition plan
- professional escalation

## Country
Changing the country updates:
- language choices
- local food vocabulary
- recipes
- composition context
- recommendations
- country dashboard

## Human care
AI is not the only path:
- nutritionist discovery
- language/specialty filtering
- chat
- appointment request
- consultation modes
- payment

## Government
Switching to institutional mode exposes Health and Agriculture command centers without mixing identifiable citizen health records into population dashboards.
