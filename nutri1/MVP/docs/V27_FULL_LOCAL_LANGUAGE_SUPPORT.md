# NUTRI.N°1 V27 — Full Local Language Interface

Base: V26 Correct Sidebar Order.

Requested enhancement:
- Keep existing V26 architecture and navigation.
- When the user selects a language, the platform UI changes language.
- English and French behavior is preserved.
- Togo local-language support is added for Ewe and Kabyè.
- Translation applies to visible navigation labels, key dashboard titles, common interface labels and placeholders.
- Existing country/language selector is reused; Ewe and Kabyè options are added only if absent.

Important: The Ewe and Kabyè strings in this prototype are interface translations for demonstration. Before production deployment, they should be reviewed and validated by native-speaking linguists/nutrition professionals in each target country. Medical/nutrition terminology should be professionally localized, not machine-translated blindly.
