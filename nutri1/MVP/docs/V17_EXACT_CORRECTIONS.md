# V17 Exact Corrections

The original V17 interface is the source of truth.

Only these additions/corrections were made:
1. Create your platform profile is now a compact native dropdown/details menu. It does not occupy dashboard space when closed.
2. The original V17 Country selector and Language selector were preserved unchanged.
3. The original V17 Country-specific Payments implementation was preserved unchanged.
4. Nutritionist Network now has an independent, populated Country dropdown using the same V17 country list.
5. Nutritionist Network country selection updates the displayed nutritionist cards and selected specialty.
6. The supplied NUTRI.N°1 logo was added to the existing sidebar brand.

No overlay/login gate was added and no V17 dashboard module was removed.
