# Prevention Framework

## Malnutrition
The platform supports:
- undernutrition screening
- overweight/obesity monitoring
- nutrition-risk context
- referral workflows

For children and other vulnerable populations, interpretation follows validated country protocols.

## NCDs
The prevention engine can organize risk-context signals around:
- diabetes
- hypertension
- cardiovascular disease
- obesity
- selected cancer-related nutrition risk contexts

The engine should not diagnose disease. It provides prevention guidance, uncertainty and professional referral where appropriate.

## Recommendation hierarchy
1. Safe general nutrition guidance
2. Country-specific food alternatives
3. Personalized meal suggestions
4. Behavioral goals
5. Monitoring
6. Professional escalation

Recommendations must be evidence-linked and versioned.
