# NUTRI.N°1 V41 — Scanner, AI Plan, Nutritionist & Health Command Center

V41 restores the requested interactions on top of the V20 dynamic visual baseline.

1. AI Food & Meal Scanner
   - Clicking scan opens a visible scan stage.
   - Animated scan line + progress.
   - Processing phases are shown.
   - Completion displays estimated energy, protein, carbohydrate and fiber.

2. AI Nutrition & Prevention
   - Generate Personalized Plan is interactive.
   - A processing message is shown.
   - A seven-day menu is generated progressively.

3. Nutritionist Network
   - Country selector populated with deployment countries.
   - Specialty selector populated with clinical/nutrition specialties.
   - List filters by both country and specialty.
   - Chat opens for selected nutritionist.
   - Messages can be sent and an assistant response appears.

4. Ministry of Health Command Center
   - Restores Children — double burden, Pregnant & lactating women and NCD trends chart rendering.
   - Uses Chart.js when available.
   - Existing page locations/canvases are reused rather than adding a replacement dashboard.

All previously validated V20/V17/V34-V37 features are retained in the base package.
