# Multilingual African Nutrition Knowledge Layer

## Levels
1. Official national language UI.
2. Major local language UI where translation resources exist.
3. Food/ingredient names in local languages.
4. Audio/voice support.
5. Low-literacy visual guidance.

## Languages
The country registry starts with official languages and representative local-language targets. Production language packs must be reviewed by native speakers and nutrition professionals.

## Togo example
French + Ewe + Kabyè + Tem + Mina + Kotokoli, with additional local variants as data/linguistic resources permit.

## AI localization
The AI should resolve local food names, synonyms and code-switching to the canonical African Food Ontology before nutritional calculation.
