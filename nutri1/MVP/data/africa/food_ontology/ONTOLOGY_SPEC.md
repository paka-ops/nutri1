# African Food Ontology

Every food should have:
- canonical identifier
- scientific name when available
- common English/French name
- country
- local names
- synonyms
- raw/cooked/processed state
- food group
- processing method
- portion units
- external database mappings
- provenance
- validation status
- version

The same food can have multiple country names while retaining one canonical identity when scientifically justified.
