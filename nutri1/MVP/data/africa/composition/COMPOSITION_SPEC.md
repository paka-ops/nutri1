# African Food Composition Database

Sources can include:
- FAO/INFOODS
- national food composition tables
- peer-reviewed literature
- validated laboratory analyses
- research projects
- manufacturer data where appropriate and clearly labeled

Each nutrient value stores:
value + unit + basis + analytical method + laboratory/source + country + quality + version.

Conflicting values must not be silently averaged; provenance and methodological differences must remain visible.
