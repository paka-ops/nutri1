# African Nutrition Evidence Graph

Nodes:
Food / Nutrient / Dietary pattern / Biomarker / Risk factor / Condition / Population / Country / Intervention.

Edges:
associated_with / increases / decreases / source_of / contains / culturally_common / recommended_for / contraindicated_in / evidence_supports.

Each edge retains:
- source
- evidence level
- population
- country scope
- date
- model/evidence version.

The graph supports recommendation retrieval but does not replace clinical judgment.
