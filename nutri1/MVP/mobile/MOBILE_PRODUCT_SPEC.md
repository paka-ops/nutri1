# NUTRI.N°1 Unified Mobile

## Navigation
Home → Scan → Food Journal → Metabolic → Prevention → Plan → Nutritionist → Profile.

## Input modes
- manual
- camera
- voice
- connected devices
- Apple Health / HealthKit where available
- Android Health Connect where available

## Languages
Official and selected local languages per country, plus local food names and voice support where resources allow.

## Scanner
Food scanner and meal scanner always allow user correction before journal confirmation.

## Prevention
Personalized recommendations are generated from country-specific foods, recipes, user profile, nutrition history, anthropometry, metabolic data, clinical context and evidence.
